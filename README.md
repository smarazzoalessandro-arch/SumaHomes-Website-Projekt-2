# SumaHomes – Website

Arbeitsprojekt für Visual Studio Code.

## Start

Den gesamten Ordner `SumaHomes-Website` in Visual Studio Code öffnen und anschließend `index.html` im Browser oder mit Live Server starten.

## Struktur

- `index.html` – Aufbau und Inhalte der Website
- `assets/style.css` – Hauptgestaltung und mobile Darstellung
- `assets/pool.css` – Pool-Projektbereich
- `assets/languages.css` – Sprachwahl
- `assets/site.js` – Sprachumschaltung und Jahreszahl
- `assets/*.jpeg`, `assets/*.png` – vorhandenes Bildmaterial

## Aktueller Stand

Editorial-Entwurf mit weißer Grundgestaltung, dezenten grünen Akzenten und drei gleich großen Bildern pro Galerie. Die bearbeiteten Bildserien für Microcemento, Mortex und Concreseal sind bereits eingebunden.

## Kleine Änderungen

- Inhalte und Bildreihenfolge: `index.html`
- Farben, Abstände, Schriften und mobile Ansicht: `assets/style.css`
- Sprachumschaltung: `assets/site.js`

Vor größeren Änderungen immer zuerst einen Git-Zwischenstand erstellen.
